# Broader recommendation source review

Reviewed September 5, 2026. This is a targeted source review, not an exhaustive literature review.

## Incorporated into implementation guidance

- Google Search Central, helpful content: https://developers.google.com/search/docs/fundamentals/creating-helpful-content. Added a task-specific authorship workflow. Never invent credentials or treat a byline as proof of expertise.
- Google Search Central, links: https://developers.google.com/search/docs/crawling-indexing/links-crawlable. Added contextual linking and destination checks to the existing curation task. This is a manual implementation check, not a new sitewide orphan-page detector.
- Google Search Central, AI features: https://developers.google.com/search/docs/appearance/ai-features. Linked platform-specific eligibility documentation in technical implementation guidance. No special AI markup is required for Google's AI search features.
- OpenAI crawler documentation: https://developers.openai.com/api/docs/bots. Linked the independent search and training controls. No crawler policies were changed.

The app and weekly digest share instructions and source links. These implementation references supplement, rather than replace, the evidence classification of the original audit finding. Existing Zyppy attribution remains.

## Considered, not implemented

- IndexNow documentation: https://www.indexnow.org/documentation. Potential future CMS publishing integration. Requires ownership verification, URL selection, retries and explicit publishing integration work. No indexing submissions or keys were created.
- Bing Webmaster Guidelines: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a. Browser-readable article body was not returned by the research tool. Do not derive new rules from this incomplete retrieval.
- Further independent studies and practitioner experiments remain candidates for a subsequent review. No new experimental ranking weights or numerical lift claims were added.

## Release boundaries

No scoring changes, new automatic detection rules, provider requests, email sends, schedules, billing or authentication changes. Broader commercial landing-page work remains separate. Preview and publication are separate release steps.
